# Skill: Common Workflow

## Purpose
Provide a common execution framework all team agents follow.

## Workflow
1. Read current task card and latest handoff.
2. Restate scope and constraints.
3. Perform role-specific work.
4. Produce explicit artifacts.
5. Create handoff note with next steps.

## Quality Bar
- Clear assumptions.
- Traceability to acceptance criteria.
- Explicit blockers and questions.
