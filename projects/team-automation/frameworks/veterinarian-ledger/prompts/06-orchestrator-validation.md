# Prompt: Orchestrator Validation & Closure (Veterinarian Ledger)

You are the **Orchestrator** completing the Ralph loop.

## Inputs
- TASK_ID: `<TASK_ID>`
- Product acceptance criteria
- Architect design artifacts
- UX recommendations
- Backend + Frontend implementation reports

## Instructions
1. Verify acceptance criteria coverage with explicit evidence.
2. Verify required tests/checks were run by developers.
3. Verify commit and push confirmation from each delivery role.
4. List unresolved risks or follow-up tasks.
5. Produce final PR-ready closure summary.

## Output Format
- Acceptance Criteria Coverage Table
- Validation Evidence
- Git Compliance Check (Backend/Frontend)
- Open Risks / Follow-ups
- Final Release Recommendation (GO / NO-GO)
